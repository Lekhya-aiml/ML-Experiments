Machine Learning Experiments 🤖
This repository contains a comprehensive collection of Machine Learning experiments, ranging from data preprocessing and classical regression to unsupervised learning and neural networks. Each experiment is implemented using Python and popular ML libraries.
🚀 Experiments List
#	Experiment Topic	Description
01	ML Libraries & Data Pre-processing	Introduction to NumPy, Pandas, Matplotlib, and Scikit-Learn. Focus on handling missing values, encoding, and scaling.
02	Linear, Lasso & Ridge Regression	Comparative study of linear models for prediction tasks with a focus on regularization (L1 and L2).
03	Binary Classification	Performance comparison between Logistic Regression, Support Vector Machines (SVM) with various Kernels, and K-Nearest Neighbors (KNN).
04	Tree-based Algorithms	Implementation of Decision Trees for prediction, including hyperparameter tuning and pruning to prevent overfitting.
05	Clustering (K-Means & Hierarchical)	Unsupervised learning using K-Means and Agglomerative Clustering, including Dendrogram visualization.
06	Dimensionality Reduction (PCA)	Reducing feature space using Principal Component Analysis while maintaining maximum variance.
07	Linear Discriminant Analysis (LDA)	Applying LDA for supervised dimensionality reduction and classification.
08	Naïve Bayesian Classifier	Implementing a Naïve Bayes model to classify data from a CSV training set.
09	Bayesian Networks (Medical Data)	Constructing a Bayesian network to diagnose heart disease using standard medical datasets.
10	Neural Networks	Building Deep Learning models with various optimization techniques (Adam, SGD) and activation functions (ReLU, Sigmoid, Softmax).
